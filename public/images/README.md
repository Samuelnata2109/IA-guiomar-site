# Fotografias reais das atividades

Adicione fotografias autorizadas nas pastas de cada disciplina e cadastre os caminhos em `src/data/courses.ts`, em `images[].src`, usando `./images/<disciplina>/<arquivo>.webp`.

Preencha `alt` e `caption` com descrições verificadas. Até lá, os modais mostram espaços explicitamente identificados, sem imagens fictícias de estudantes. Redimensione e comprima as imagens antes da publicação; preserve a proporção original.
